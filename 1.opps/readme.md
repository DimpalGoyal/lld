## classes and object

- class: template and blueprint
- object: instance of a class
- attributes: variables inside a class
- methods: functions inside a class
- self: used as a parameter in methods to access the class attributes
- annotation: type suggestions
- constructor: **init**

---

- inheritance: childing inheriting parent traids, like dog and cat are the childrens of animal
- super(): to access the parent constructor inside a child
- method overRiding: different methods having many names, if child and parent having same method name than child one overRides the parent one
---

- encapsulation: making attributes and method public and private, we can private them by using double-underScore(**). ex-> balance becomes **balance
- getters and setters: exposing private variable through methods
