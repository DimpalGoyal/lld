## SOLID principles

### S - single responsibilty principle(SRP)
- a class should have only one reason to change
- each class should focus on one task only

### O - open close principle(OCP)
- open for extension: you can add new features easily
- closed for modification: don't change existing working code

### L - liskov substitution principle(LSP)
- objects of a parent class should be replaceable with objects of a child class without breaking the program

### I - interface segregation principle(ISP)
- ensures that classes are not forced to implement the methods which they don't need
- breaking large, general-purpose interfaces into smaller, more specific ones
